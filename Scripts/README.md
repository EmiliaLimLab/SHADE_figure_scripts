# Automated Quantification of Anthracotic Pigment in Normal Lung Tissue from Lung Cancer Patients - Data Analysis

This repository contains the R scripts used for analysis in the manuscript.

`fig_6_bccancer_neversmoker_analysis` refers to the analysis used for the BC Cancer LCINS cohort, generating Figure 6 of the manuscript.
Likewise, `fig_7_bal_cohort_analysis` refers to the gene expression analysis used for the BAL cohort, generating Figure 7 of the manuscript.
