# Clinical and Molecular Correlates of Digitally Quantified Anthracosis in Lung Tissue Slides: Utility of an Automated Quantitative Workflow - Data Analysis

This repository contains the R scripts used for analysis and creation of Figures 4-6 in the manuscript.

`fig_4&5_analysis` refers to the analysis used for the never-smoking and ever-smoking cohort, generating Figures 4 and 5  of the manuscript.
Likewise, `fig_6_bal_cohort_analysis` refers to the gene expression analysis used for the gene expression cohort, generating Figure 6 of the manuscript.
