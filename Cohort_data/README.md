# Clinical and Molecular Correlates of Digitally Quantified Anthracosis in Lung Tissue Slides: Utility of an Automated Quantitative Workflow - Cohort Data

This folder contains all data for all cohorts used in the manuscript.

`BAL_Cohort.csv`, `BAL_nanostringdata.xlsx`, and LBL-10043-08_nCounter_PanCancer_Immune_Profiling_Panel_Gene_List_Annotations.csv` contains all data pertaining to the gene expression cohort.

`LCINS_Cohort.csv` contains data regarding the never-smoking cohort.

`Smoking_Cohort.csv` contains data pertaining to the ever-smoking cohort.
